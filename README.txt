Voice Game (browser demo)
1. Run:  python3 serve.py      (Windows: py serve.py)
2. Open http://localhost:8000 in Chrome, Edge or Firefox.
3. Wait for the model to load, allow the microphone, then speak:
   "bravo three nine please respond" or "unidentified craft in grid delta five identify".
Microphone access only works on localhost or https, so do not open index.html directly.
